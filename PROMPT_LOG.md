Источник данных: Счётчики электроэнергии (эмуляция)
Оконная агрегация в Go перед отправкой в Python

Добавить в сборщик оконную агрегацию (tumbling window). Например: каждые N секунд или каждые M записей агрегировать данные на стороне Go и отправлять в Python не исходные записи, а уже агрегированные (суммы, средние и т.д.). Это снижает объём передаваемых данных.

Выполни это задание, исправь README, после выполнения закоммить и запуш на GitHub
```

**Результат:** Реализована оконная агрегация (tumbling window) на стороне Go-сборщика. Создан пакет internal/aggregator с двумя режимами: time-based (флаг -agg-window, например 30s) и count-based (флаг -agg-count, например 100 записей). Агрегатор интегрирован в collector: сырые показания накапливаются в окне, по его закрытию выводится AGGREGATED JSON с sum/avg/min/max power_kw, avg_voltage_v, avg_current_a и count. При graceful shutdown выполняется final flush остатков окна. Обновлён cmd/collector/main.go (флаги -agg-window, -agg-count), Makefile (цели run-agg-time, run-agg-count, run-agg-time-all), README.md (документация, архитектурная диаграмма, примеры вывода). Сборка успешна, изменения закоммичены и запушены на GitHub.

- Ток (current_a): 0–500 А
- Временная метка (timestamp): не в будущем, не раньше 2020-01-01
- Локация (location): не пустая, не длиннее 100 символов

Требования к реализации:
1. Rust-библиотека как cdylib/staticlib с C-compatible API
2. Функции: ping, validate_reading (одна запись), validate_readings_batch (массив), free_string
3. Все функции возвращают JSON-строки через C-указатели
4. Go-обёртка через cgo с вызовом Rust-функций
5. Метод Validate() в структуре Reading
6. Флаг -validate в collector для включения валидации
7. Makefile-цели для сборки Rust и Go+Rust
8. Статическая линковка Rust-библиотеки в Go-бинарник

Выполни это задание, обнови README, после выполнения закоммить и запуш на GitHub
```

**Результат:** Создана Rust-библиотека валидации (rust_validator/src/lib.rs) с 12 unit-тестами (все проходят). Реализован C-compatible API: validate_reading, validate_readings_batch, free_string. Создана Go-обёртка (internal/validator/validator.go) через cgo со статической линковкой. Добавлен метод Validate() в Reading (internal/source/source.go). Добавлен флаг -validate в collector (cmd/collector/main.go, internal/collector/collector.go). Обновлён Makefile (цели rust-build, rust-test, rust-clean, build-with-rust, run-with-rust). Решена проблема с кириллическими путями на Windows при линковке через gcc — .lib скопирован в C:\rust_lib\, добавлены системные библиотеки (-lws2_32 -luserenv -lntdll).
